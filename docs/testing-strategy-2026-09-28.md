# Тестирование без браузера: результат внедрения

28 сентября 2026. Исходная точка: master, a421417.

## Идентификаторы и два исходных дефекта

RFC о глобально уникальных ID отменён. Сохраняется составная идентичность (sourceId, drawingId); одинаковые локальные ID разных владельцев допустимы. Тестовые данные не переименованы.

- History.clear() создаёт новую исходную позицию и очищает обе ветки истории даже после полного undo, сохраняя состояние графика.
- UpdateEntry.mergeWith() учитывает storage: изменения разных источников не объединяются по одному локальному ID. Отдельные проекции сохраняют собственные уведомления.
- Регрессии закреплены в tests/unit/model/history/HistoryBoundaries.spec.ts.

## Реализация

Расчёт размеров и drag панелей вынесены из Multipane.vue в packages/layout/src/model/pane-layout.ts. Компонент измеряет DOM и применяет результат. Chart.recordPaneResize владеет записью resize в историю.

Рисование labels/grid выделено в функции, вызываемые workers и Node-тестами. Настоящие sketchers и слои проверяются через запись Canvas-команд/Path2D, метрики текста задаются тестом. Нового промежуточного формата сцены в рабочем рендеринге нет.

Большой screenshot-сценарий заменён проверками состояния, геометрии и каждого промежуточного undo/redo. Независимая модель хранит снимки и стеки past/future без использования incidents продукта. Генератор меняет последовательности и сокращает падения. Есть 144 пары операций, проверки временной группировки, shared-проекций и восстановления удалённых панелей.

Базовые screenshot-сценарии перенесены в layout/render contracts. Четыре browser-теста оставлены для DOM, native hit testing и событий без PNG. Карта покрытия и команды: [TESTING.md](../TESTING.md).

## Дополнительные найденные регрессии

- Протокол сохранял hooks только последнего источника, поэтому undo первого не уведомлял подписчиков. Теперь регистрируются hooks всех источников с дедупликацией.
- Resize равных панелей мог зациклиться из-за дробного остатка. При достижении ограничений присваивается точное граничное значение; число итераций ограничено.
- Preferred size мог нарушать индивидуальный minSize, когда сумма предпочтений совпадала с доступным местом. Ограничения применяются и здесь.
- Кэш ценовых меток не учитывал font, fraction и контекст измерения. Теперь смена этих входов сбрасывает кэш; проверяется также undo стиля.

## Границы

Команды Canvas не проверяют сглаживание, форму букв и все браузеры. Генератор не является исчерпывающим доказательством: live binding, динамический shareWith и не реализованные API перестановки рисунков не входят в модель. Порядок рисунков при удалении/восстановлении проверяется.

[ADR0006](decisions/ADR0006-browser-free-testing.md) фиксирует архитектуру тестирования и test-only зависимость fast-check. Это не отменённый RFC об идентификаторах.
